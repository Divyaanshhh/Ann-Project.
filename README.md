## 🛰️ Multi-Modal Six-Channel Geospatial Representation

The model operates on a strict 5D spatiotemporal tensor convention:
- **Input Tensor**: `(Batch, Time=5, Channels=6, Height=128, Width=128)`
- **Target Tensor**: `(Batch, Time=3, Channels=1, Height=128, Width=128)` (corresponding to **+12h**, **+24h**, and **+48h** horizons)

| Channel | Layer | Description | Normalization & Physical Units |
|---|---|---|---|
| **C1** | Fire Perimeter & Intensity | Observed active fire mask and thermal radiance | $[0.0, 1.0]$ |
| **C2** | NDVI Vegetation Index | Sentinel-2 derived fuel biomass density | $[-1.0, 1.0] \rightarrow [0.0, 1.0]$ |
| **C3** | Terrain Slope & Aspect | DEM-derived topographical spread risk | $[0.0, 1.0]$ |
| **C4** | Wind Velocity | Surface wind speed field magnitude | $[0.0, 35.0] \text{ m/s} \rightarrow [0.0, 1.0]$ |
| **C5** | Wind Direction | Circular angle representation | Cyclic trigonometric mapping $[0.0, 1.0]$ |
| **C6** | Atmospheric Dryness | Vapor Pressure Deficit / Temperature + Relative Humidity | Composite index $[0.0, 1.0]$ |

## 🧠 Deep Learning Architecture & Compound Loss

### Stacked ConvLSTM Cell Equations
$$\begin{aligned}
i_t &= \sigma(W_{xi} * x_t + W_{hi} * h_{t-1} + b_i) \\
f_t &= \sigma(W_{xf} * x_t + W_{hf} * h_{t-1} + b_f) \\
o_t &= \sigma(W_{xo} * x_t + W_{ho} * h_{t-1} + b_o) \\
g_t &= \tanh(W_{xg} * x_t + W_{hg} * h_{t-1} + b_g) \\
c_t &= f_t \odot c_{t-1} + i_t \odot g_t \\
h_t &= o_t \odot \tanh(c_t)
\end{aligned}$$

### Custom Compound Loss Function
To address extreme foreground/background spatial sparsity of wildfire perimeters:
$$\mathcal{L}_{\text{Total}} = \lambda_{\text{focal}} \mathcal{L}_{\text{Focal}}(p_t, y_t) + \lambda_{\text{intensity}} \mathcal{L}_{\text{MSE}}(I_t, \hat{I}_t)$$
where:
$$\mathcal{L}_{\text{Focal}} = -\alpha_t (1 - p_t)^\gamma \log(p_t) \quad (\alpha=0.75, \gamma=2.0)$$

## 🚀 Quickstart & Execution Workflow

### 1. Environment Setup
```bash
# Create virtual environment
python -m venv .venv
.\.venv\Scripts\activate

# Install dependencies (with PyTorch CUDA)
pip install -r requirements.txt
```

### 2. Generate Synthetic Benchmark Dataset
```bash
python -m datasets.synthetic_generator
```
Generates 100 physically simulated samples in `data/synthetic/synthetic_wildfire_dataset.npz`.

### 3. Train Model on GPU
```bash
python -m training.trainer --epochs 20 --batch-size 8 --model-type convlstm
```
Automatically utilizes GPU (NVIDIA GeForce RTX 3050 Laptop GPU) and outputs `data/checkpoints/best_model.pt`.

### 4. Evaluate Model across Forecast Horizons
```bash
python -m training.evaluator
```
Evaluates +12h, +24h, and +48h IoU, Dice, Precision, Recall, and F1.

### 5. Launch Interactive Research Dashboard
```bash
streamlit run app.py
```

### 6. Run Automated Test Suite
```bash
pytest tests/ -v
```

- **Binary Cross-Entropy (BCE)**
- **Intensity Mean Absolute Error (MAE)**
